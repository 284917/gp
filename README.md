# Голос компании

Платформа программы амбассадоров бренда работодателя: кабинет амбассадора для сотрудников и студентов и кабинет куратора для управления программой.

Проект команды для кейса **Intelligence CUP** («HR и бренд работодателя — программа амбассадоров»).

## Что умеет

**Публичная часть**
- Главная страница программы: кто такие амбассадоры, путь из четырёх уровней, сезон сентябрь — май, награды, вопросы.
- Заявка в программу: роль (офис, АЗС и нефтебаза, вуз, колледж), регион, место работы или учёбы, мотивация, согласие на обработку данных.

**Кабинет амбассадора** (`/me`)
- Путь: уровень и баллы, цель недели, тандем «сотрудник + студент», сезон, уведомления.
- Задания недели под свою роль, сдача текстом, ссылкой или файлом (фото, видео, голосовое), история проверки.
- Контент-кит: конструктор поста, ключевые сообщения, сценарии роликов, памятка «можно / нельзя», каналы.
- Рейтинг региона и кубок регионов (по среднему баллу).
- Награды: обмен баллов на опыт, обучение, карьерные возможности и мерч.
- Профиль, история заданий, бонусные баллы, смена пароля.
- Для капитанов регионов — проверка заданий своего региона.

**Кабинет куратора** (`/curator`)
- Обзор: что требует внимания, ключевые показатели, контент по неделям, нагрузка кураторов и капитанов, активность по сегментам, воронка «от публикации до найма», метрики программы с целями сезона.
- Модерация заданий, заявки в программу, выдача наград.
- Амбассадоры: поиск и фильтры, карточка с историей, назначение капитана, пауза, наставник-тандем, бонусные баллы, напоминания.
- Задания: публикация и редактирование, аудитория, способ сдачи, кто проверяет.
- Регионы: схема с часовыми поясами, капитаны, активность.
- Метрики: ежемесячный ввод охвата, откликов, наймов и заявок на практику.

## Технологии

- Next.js 15 (App Router, серверные компоненты и server actions), React 19, TypeScript.
- PostgreSQL через библиотеку `postgres`. Схема — в `migrations/`, применяется автоматически при сборке.
- Вход по почте и паролю (bcrypt), сессия в подписанном cookie (JWT).
- Загрузка файлов — Vercel Blob (необязательно).
- Шрифты Golos Text и Roboto Condensed подключены локально, без внешних запросов.

## Запуск на Vercel

1. **Импорт проекта.** На vercel.com: *Add New → Project*, выберите репозиторий `284917/gp`. Настройки сборки менять не нужно.
2. **База данных.** В проекте откройте *Storage → Create Database → Neon (Postgres)* и подключите её к проекту. Переменные `DATABASE_URL` и другие появятся автоматически.
3. **Переменные окружения** (*Settings → Environment Variables*):
   - `AUTH_SECRET` — длинная случайная строка (например, результат `openssl rand -hex 32`).
   - `ADMIN_EMAIL` и `ADMIN_PASSWORD` — почта и пароль главного куратора (пароль от 8 символов). При каждой сборке этот аккаунт создаётся или получает роль куратора и пароль из переменной — так доступ всегда можно восстановить через Vercel.
   - `DEMO_MODE` — `true`, чтобы показать продукт с демо-данными и кнопками быстрого входа; `false` для боевого запуска.
4. **Файлы (по желанию).** *Storage → Create → Blob*, подключите к проекту — появится `BLOB_READ_WRITE_TOKEN`, и амбассадоры смогут прикреплять фото, видео и голосовые.
5. **Пересоберите проект:** *Deployments → … → Redeploy*. При сборке создаются таблицы, справочники и демо-данные.
6. **Проверка:** откройте `/api/health` — должно быть `"ok": true` и `"database": "connected"`.

Для боевого запуска поставьте `DEMO_MODE=false` — кнопки демо-входа исчезнут, а новые демо-данные не будут создаваться. Уже созданные демо-записи помечены в базе флагом `is_demo`.

## Локальная разработка

```bash
npm install
cp .env.example .env.local   # укажите DATABASE_URL своей базы Postgres
npm run db:migrate           # таблицы и начальные данные
npm run dev                  # http://localhost:3000
```

## Проверка качества

Каждый push запускает GitHub Actions (`.github/workflows/ci.yml`): установка, миграции на чистой базе Postgres, сборка, повторный запуск миграций и автотест основного сценария в браузере — заявка → одобрение куратором → сдача задания → проверка капитаном → начисление баллов → обмен на награду, а также мобильная версия и тёмная тема. Скриншоты всех экранов сохраняются в артефакте `screenshots`.

## Структура

```
migrations/          SQL-схема базы
scripts/migrate.mjs  миграции и начальные данные (запускается при сборке)
scripts/seed.mjs     справочники: регионы, задания, награды; демо-данные
scripts/smoke.mjs    автотест сценариев в браузере
src/app/             страницы: главная, вход, заявка, /me, /curator
src/app/actions/     серверные действия: вход, задания, проверка, управление
src/components/      интерфейс: карточки, формы, графики, навигация
src/lib/             база, сессии, справочники программы, статистика
```
